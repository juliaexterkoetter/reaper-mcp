# Code of conduct

Be respectful, patient and specific. Critique code and ideas without personal
attacks. Welcome contributors of different backgrounds, abilities and experience.
Harassment, threats, discriminatory language, doxxing and unwanted contact are
not acceptable in project spaces.

Maintainers may remove harmful content, close disruptive discussions or restrict
participation. Report a concern to the repository owner through an available
private GitHub contact; if no private channel is available, request one without
posting sensitive details. Reports should be handled confidentially where
possible, fairly, and without retaliation.
