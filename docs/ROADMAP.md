# Roadmap

Work in isolated feature branches, validate and merge before the next feature.

1. Architecture and documented decisions.
2. MCP foundation, CLI and protocol tests.
3. Test-only mock bridge.
4. Native extension and authenticated local bridge.
5. Projects, tracks, media items, takes, transport, FX.
6. Markers/regions, automation, render and environment discovery.
7. Installer, Codex registration and diagnostic workflow.
8. Windows CI, standalone packaging and prerelease.
9. Real Windows/REAPER/Codex acceptance test, then stable release.

Planned beyond initial release: semantic mixing, audio measurements, video,
ARM/macOS/Linux runtime ports, multi-instance selection, preset application.
No feature is supported until implemented and validated; see MCP_TOOLS.md.
